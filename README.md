# SpotiDisplay
A small portable circular touchscreen display for controlling Spotify.

<br></br>

I made this so that I can control my music while at my desk without reaching for my phone but instead just from my laptop, and I can have the convenience if portability from a small and stylish device.

<br></br>

# To make:

Plug the ESP32-S3 into the round display and the antennae.

<br></br>

Connect the battery to the display from underneath the ESP32-S3

<br></br>

Open the driver.h and SpotiDisplay.ino files in Arduino IDE

<br></br>

Upload the sketch after installing the touch display for seeeduino xiao library

<br></br>

Run the script on you Mac from terminal (nano spotidisplay.py, then copy paste the conents into the file, then run python3 spotidisplay.py (need to have python 3 installed, too))

<br></br>

Assemble the case (pretty easy)

<br></br>

Enjoy!!

<br></br>
